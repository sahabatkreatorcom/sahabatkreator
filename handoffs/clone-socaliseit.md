## Keputusan penting
- (tetap) Semua poin keputusan lama berlaku.
- **Scheduling memakai BullMQ** (delay-based, in-process worker via instrumentation) sebagai jalur utama; `/api/cron/publish` jadi fallback/safety-net. Tidak pakai ioredis langsung — Redis hanya via BullMQ.
- **Cron fail-closed**: semua endpoint cron tolak bila `CRON_SECRET` kosong. `CRON_SECRET` wajib di production.
- `ENCRYPTION_KEY` wajib di production (jangan bergantung fallback derive BETTER_AUTH_SECRET).
- Route tulis admin wajib `requireAdmin`; route tulis user wajib `withAuth`/`requireAuth`.
