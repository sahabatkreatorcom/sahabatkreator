## Page Mentions TIDAK render sebelum approval — TERVERIFIKASI eksperimen

User laporkan: post FB berhasil publish tapi mention (`@[page-id]`) tidak muncul,
padahal: (1) admin dari kedua Halaman, (2) "Others Tagging this Page" aktif di
keduanya, (3) text-only & image sama-sama gagal.

Investigasi via DB Neon langsung + Graph API read-back:
- Kode BENAR — `platformSettings.mentions` tersimpan di DB (`["1272001186005103"]`),
  adapter `withPageMentions()` append `@[id]` dengan signature `\n\n`.
- Graph API read-back post asli: `message` = `"...indonesia\n\n"` — token `@[id]`
  **DISTRI Facebook**, `message_tags` kosong.
- Eksperimen kontrol: post LANGSUNG via Graph API (bypass app) dengan `@[id]`
  eksplisit → hasil SAMA (200 OK, token distrip, no message_tags). Token = PAGE
  token valid bawa `pages_manage_posts`.

KESIMPULAN: `@[page-id]` di **post** (bukan comment) di-gate oleh approval fitur
Page Mentions. Facebook silently strip syntax sampai disetujui. Klaim sebelumnya
"bisa dipakai di Development mode" SALAH (itu berlaku untuk *comment*, docs
"Comments and @mentions"). Doc sudah dikoreksi (docs/Jawaban-App-Review-Meta.md
bagian "FINDING TERVERIFIKASI"). Screencast submit harus tunjukkan token terkirim
(GET /{post-id}?fields=message,message_tags), bukan mention hidup.
