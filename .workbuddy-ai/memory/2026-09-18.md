## AI Auto-Reply (komentar & DM) — commit f1c6e23

Rekomendasi delay-vs-implement diterapkan: DM 0.5-2 mnt, komentar 2-5 mnt,
negatif skip + human review, dry-run untuk onboarding.

Arsitektur kunci:
- `automationRule.action` jadi discriminated union: `reply` (template statis,
  kirim instan) vs `ai_reply` (tone + delayMinutes + dryRun)
- `processAutomation` (publishing/automation.ts): match → insert
  `automation_log` status `pending` + `due_at` → enqueue delayed job
- `processAutoReplyJob` (publishing/auto-reply.ts): claim atomik
  (`SET due_at=NULL WHERE status='pending'`), re-cek rule aktif &
  inbound segar (sudah-dibalas-manual → skip), sentiment guard, AI generate
  (1 kredit), kirim / simpan draft (dryRun → `engagement_item.draft_reply`)

  polling `due_at` 30s — sama pola dengan reminder
- **Cross-package constraint**: publishing TIDAK boleh import queue (cycle).
  Solusi: `queue-hook.ts` DI (`registerAutoReplyEnqueue`) — server & worker
  register saat boot. Tanpa host → fallback polling jalan otomatis
- Worker butuh AI tapi `lib/ai.ts` ada di apps/server → buat copy di
  `publishing/ai.ts` (pola yang sama dipakai `crypto.ts`: "salinan identik")

Sentiment guard: `publishing/sentiment.ts` keyword negatif ID + emosi
(tanda baca/kapital). Negatif → skip, flag `sentiment='negative'`, no credit.

Migration: `packages/db/scripts/apply-automation-ai.ts` — jalankan manual
(tanpa TTY drizzle-kit push): automation_log +engagement_item_id, +due_at,
+idx; engagement_item +draft_reply.

## Fix Meta OAuth + dobel hashtag — commit c076c1c

Isu user: (1) beberapa izin/fitur Meta "belum berhasil call API" —
read_insights, page_mentions, pages_utility_messaging, Human Agent,
pages_user_gender; (2) error OAuth "Invalid Scope: pages_user_gender";
(3) caption AI sudah ada hashtag → form hashtag dobel saat publish.

Root cause 1+2 (saling terkait):
- `pages_user_gender` ada di OAUTH_CONFIGS.facebook.scopes. Permission itu
  membaca gender *orang* (context Messenger), BUKAN untuk page_fans_gender_age.
  Memintanya membatalkan SELURUH authorize → login FB gagal total → semua
  trigger FB-side return "No Facebook account connected" (itulah sebabnya
  read_insights/page_mentions "belum berhasil call API").
- `read_insights` (permission benar untuk Page Insights) TIDAK ada di scope.
- Fix: hapus pages_user_gender, tambah read_insights
  (packages/publishing/src/oauth/platform-configs.ts).
- pages_utility_messaging & human_agent sengaja TIDAK diminta — Meta tolak
  permission yang diminta tanpa fitur yang memakainya.

Root cause 3:
- Prompt lama: "Sertikan 3-8 hashtag di akhir caption" → hashtag di caption
  body. composeCaption(content, hashtags) tempel field hashtag lagi saat
  publish → dobel.
- Fix: prompt baru minta caption bebas '#', hashtag di baris 'HASHTAG:'
  terpisah; server parse & pisah; frontend auto-merge ke field hashtag.
